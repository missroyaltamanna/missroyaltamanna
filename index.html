01 / About

A Little About Me

I'm Tamanna — a web developer in the 7th semester of my BS in Software Engineering, focused on building interfaces that are clean, responsive and carefully considered.

Alongside my degree, I'm developing my skills in frontend development, responsive web design and modern web technologies. I care about structured, readable code and about interfaces that work just as well on a small phone as they do on a wide desktop screen.

I enjoy approaching problems creatively — breaking them into clear steps and finding solutions that are simple to use and easy to maintain. Learning is a constant part of how I work, and every project is a chance to understand something more deeply.

  1. Web Development

    A genuine interest in building for the web, from structure to interaction.

  2. Clean, Structured Code

    Semantic markup, organised stylesheets and logic that is easy to read.

  3. Responsive Interfaces

    Layouts that adapt gracefully to every screen size and device.

  4. Continuous Learning

    Consistently expanding my technical knowledge and practical toolkit.

  5. Creative Problem-Solving

    Thinking problems through carefully to arrive at clear, simple solutions.
